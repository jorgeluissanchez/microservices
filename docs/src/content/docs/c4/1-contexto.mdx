## Claves del contexto

* **Usuario como Actor Principal:** El _Usuario Suscriptor_ es la única **persona** que interactúa con el sistema, siendo el centro del negocio (pago de suscripción).
* **Alcance del Sistema Principal:** La _Aplicación de Suscripción_ es vista como una **caja negra** única en este nivel, encapsulando los microservicios auth y payment.
* **Dependencia Externa Crítica:** El sistema tiene una **dependencia fundamental** con el _Sistema de Pago Externo_ para poder cumplir con su propósito de negocio (procesar cobros).
* **Interacción:** Todas las interacciones del usuario con el sistema principal se realizan a través de un **navegador web**.
